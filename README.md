# Flow Lite

A lightweight QR-first roll cage workflow prototype.

## Run
Open `index.html` in a browser, or serve the folder with GitHub Pages / a local static server.

## Instrument panel
Use the four-square button in the top-right corner. The panel is designed so the important operational state is visible without scrolling. Click any instrument for the detailed layer.

The prototype stores data in browser LocalStorage. **Resetting browser storage removes the local demo and recorded cycles.**
